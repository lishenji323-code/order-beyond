## 新的生成约定

- 通常 40–160 字、1–3 段；开场约 80–180 字。属于生成指导，不截断模型返回的正文。
- 男主先接住玩家输入，再说话或行动，到玩家适合回应的位置停止。
- 去掉“至少留下两个未解决问题”要求；不输出作者视角的悬念问答或选项菜单。
- 不代写女主台词、心理和自愿动作；不把沉默当同意。
- 无模型时仍只有本地开场，各世界改为短场景和直接对话，题名暂为“未题”。真实题名从第一次有效模型响应取得。

## 时间与题名

模型返回 `narrative: { title, time: { day, period } }`。题名根据实际场景产生，不能等于世界、主线或原型的选项名，不能含章节编号。连续对话沿用题名，主题变更后更新。

时间使用故事内昼夜，开场第 1 天或第 1 夜；白天入夜是第一夜，第一夜天亮是第二天。同一轮不自动累加，刷新和现实离线不推进时间。正文明确过夜、入夜或跳日，模型才更新绝对天数；程序拦截时间倒退。

阅读页不再显示“第几章”。历史存档的旧章节字段只作兼容保留，新故事不产生章节计数。旧正文保留，下次有效续写补齐题名和时间。未补齐前显示“此刻 / 未题”。模型缺少必要时间与题名、题名使用选项名、时间倒退时，原存档不变，可重试。

## 验证范围

单元测试覆盖标题与时间校验、旧存档与备份、120 种开场组合；手机视口测试覆盖固定按钮、模型题名显示、同夜对话、次日转换和刷新恢复。接口测试使用受控响应，不能证明任意真实模型都能稳定遵循文风规则，仍需连接所选模型进行实际体验。
